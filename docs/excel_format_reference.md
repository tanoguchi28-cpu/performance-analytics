# Excel原本フォーマット メモ（フェーズ5 インポート機能設計用）

実運用中のExcelファイル（チーム提供、個人データを含むためリポジトリには含めない）の
列構成を記録したもの。フェーズ5（Excelインポート機能）の列マッピング設計の参照用。

## シート構成

- `ポジション別分析` / `G分析` / `F分析` / `C分析`: 集計・分析用シート（原本からの参照/加工）
- `原本`: 生データ。1行 = 1選手。`NO.`, `学年`, `P`(ポジション), `名前` に続き測定項目が並ぶ
- `202510測定結果`: 特定測定日のスナップショット（`P`列が無く、他は原本と同じ列構成）

## 列構成（原本シート、1行目=大項目・2行目=単位/小項目のヘッダー2段構成）

| 列 | 大項目(1行目) | 小項目(2行目) |
|---|---|---|
| A | - | NO. |
| B | - | 学年 |
| C | - | P（ポジション: G/F/C） |
| D | - | 名前 |
| E | 身長 | cm |
| F | 体重 | kg |
| G | スタンディングリーチ | cm |
| H | ウィングスパン | cm |
| I/J | 長座体前屈 | cm / 順位 |
| K/L | 20m スプリント（※正式名称は3/4コートスプリント。原本側の表記更新が未対応） | sec / 順位 |
| M/N | レーンアジリティー | sec / 順位 |
| O/P | 反復横跳び | 回数 / 順位 |
| Q/R | 垂直跳び | cm / 順位 |
| S/T | チェストパス | cm / 順位 |
| U/V | 上体おこし | 回数 / 順位 |
| W/X | シャトルラン | 回数 / 順位 |
| Y/Z | 懸垂 | 回数 / 順位 |
| AA/AB | P-up | 回数 / 順位 |
| AC〜AF | 身長/体重/スタンディングリーチ/ウィングスパンの順位列（末尾に再掲、原本の癖） |

チェストパスの実測値は1400〜1700程度の範囲（単位表記はcmだが、実質メディシンボール投げ等の
距離をmm相当の精度で記録している可能性がある。要チーム確認）。

## アプリのMeasurementItem.keyとの対応

| Excel項目名 | アプリkey |
|---|---|
| 身長 | height |
| 体重 | weight |
| スタンディングリーチ | standing_reach |
| ウィングスパン | wingspan |
| 長座体前屈 | sit_and_reach |
| 20m スプリント（正式名称: 3/4コートスプリント） | three_quarter_sprint |
| レーンアジリティー | lane_agility |
| 反復横跳び | side_step |
| 垂直跳び | vertical_jump |
| チェストパス | chest_pass |
| 上体おこし | sit_up |
| シャトルラン | shuttle_run |
| 懸垂 | pull_up |
| P-up | push_up |

原本の該当列見出しは現状「20mスプリント」表記だが、正式名称は当初仕様どおり
「3/4コートスプリント」（原本側の表記更新が未対応なだけ）とのことなので、
アプリ側は正式名称で登録している。

## 評価基準（チーム提供の目標値、県優勝レベル）

ポジション(G/F/C)別に目標値が異なる項目: 3/4コートスプリント・レーンアジリティー・
反復横跳び・垂直跳び・チェストパス・上体おこし。
長座体前屈はポジション共通(60cm)。
シャトルランは「その年の測定結果から算出」する運用のため固定目標値なし。

これらは [seed_evaluation_criteria.dart](../lib/core/constants/seed_evaluation_criteria.dart)
に反映済み。実際の数値・出典の詳細はそのファイルのコメントを参照。
